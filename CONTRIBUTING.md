# Contributing

The rules live in [`CLAUDE.md`](CLAUDE.md) — branching and ticket format, the
rebase-not-merge policy, commit and PR conventions, the code-quality gate,
migrations, and the binding engineering rules (this repo deploys
automatically on merge). `AGENTS.md` is a symlink to the same file, so every
coding assistant and every human reads one copy.

This file exists mainly so GitHub surfaces contributing guidance in the PR
and issue UI — it's deliberately not a second copy of those rules. If
something here and in `CLAUDE.md` ever disagree, `CLAUDE.md` is correct and
this file is stale; fix this file, don't work around it.

Quick links: [branching & tickets](CLAUDE.md#branching-tickets-and-worktrees),
[pull requests](CLAUDE.md#pull-requests), [code quality gate](CLAUDE.md#code-quality-gate-enforced-not-optional).
